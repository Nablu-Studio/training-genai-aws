# Workspace Agents Tool Use

Ce workspace montre comment cadrer un agent qui appelle des outils de facon deterministe.

## Ce que vous y cherchez
- le contrat d'entree et de sortie de chaque outil
- les points d'idempotence avant un appel externe
- la trace minimale a conserver pour auditer une action

## Piste de depart
Commencez par decrire un outil en entree stable avant de laisser le modele orchestrer plusieurs appels.
