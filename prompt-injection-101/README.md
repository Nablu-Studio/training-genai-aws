# Workspace Prompt Injection

Ce workspace aide a reconnaitre et contrer les injections de prompt les plus courantes.

## Ce que vous y cherchez
- les formulations d'attaque qui tentent de contourner les instructions systeme
- les contremesures cote prompt, outils et garde-fous
- les cas ou une simple consigne textuelle ne suffit plus

## Piste de depart
Lisez d'abord quelques prompts d'attaque et essayez de les classer par intention: exfiltration, escalade, sabotage.
