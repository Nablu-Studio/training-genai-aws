# Workspace RAG Production

Ce workspace traite les arbitrages d'un RAG en production: reranking, fraicheur et seuil de confiance.

## Ce que vous y cherchez
- la difference entre retrieval correct et reponse utile
- les politiques de rafraichissement des index
- les signaux qui justifient un fallback ou une abstention

## Piste de depart
Commencez par definir quelles erreurs de retrieval sont intolerables pour votre cas d'usage.
