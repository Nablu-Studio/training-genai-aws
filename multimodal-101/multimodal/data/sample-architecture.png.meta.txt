Architecture Bedrock : un client envoie un prompt texte, Bedrock selectionne un foundation model (Nova Lite, Claude 3, Titan Image), applique les guardrails, et retourne la reponse. Les modeles personnalises sont servis via Provisioned Throughput, les modeles on-demand via la file d attente Bedrock. Le cout total inclut l inference, le stockage S3 des artefacts, et la pipeline d observabilite.
