# Workspace Observabilite 101

Ce workspace pose les traces minimales a capturer pour comprendre une requete LLM sans exposer de donnees sensibles.

## Ce que vous y cherchez
- les champs utiles: prompt version, latence, tokens, statut, score
- la difference entre logs applicatifs, traces et mesures
- les zones a redact pour limiter le risque de fuite

## Piste de depart
Ecrivez d'abord le schema de trace, puis seulement les logs techniques.
