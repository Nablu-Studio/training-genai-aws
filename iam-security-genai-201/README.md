# Workspace IAM Security GenAI

Ce workspace renforce la posture IAM d'une plateforme GenAI: limites, frontieres et traque des acces.

## Ce que vous y cherchez
- le principe de moindre privilege applique a Bedrock et aux stores associes
- l'interet des permission boundaries et des roles separes
- les symptomes d'une politique trop large pour rester auditable

## Piste de depart
Identifiez d'abord les ressources Bedrock, S3 et logs vraiment necessaires au flux cible.
