# Workspace Evals LLM

Ce workspace structure une boucle d'evaluation reproductible avec dataset, attente et score.

## Ce que vous y cherchez
- la difference entre intuition de qualite et mesure tracee
- la composition d'une bonne rubrique d'evaluation
- la facon de conserver les resultats pour comparer plusieurs runs

## Piste de depart
Commencez par un petit dataset stable, puis ajoutez les cas limites les plus couteux metierement.
