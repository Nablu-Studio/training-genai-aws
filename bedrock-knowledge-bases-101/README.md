# Workspace Knowledge Bases

Ce workspace sert a preparer une source documentaire exploitable par Bedrock Knowledge Bases.

## Ce que vous y cherchez
- la relation entre source brute, chunking et synchronisation
- les metadonnees minimales utiles pour filtrer les reponses
- les controles de fraicheur a poser avant de relancer une ingestion

## Piste de depart
Ouvrez d'abord la cartographie de vos sources et decidez quelles metadonnees resteront stables dans le temps.
