# Workspace Cost Capacity

Ce workspace aide a arbitrer cout, debit et latence sur une charge GenAI reelle.

## Ce que vous y cherchez
- le cout total d'une requete, pas seulement le prix unitaire du modele
- les gains possibles par batching, caching et priorisation
- les signaux qui montrent qu'un modele est surdimensionne pour le besoin

## Piste de depart
Debutez par une matrice simple volume x criticite x delai acceptable.
