# Workspace Vector Stores AWS

Ce workspace sert a comparer plusieurs options de stockage vectoriel dans un contexte AWS.

## Ce que vous y cherchez
- les compromis entre cout, latence, filtres et exploitation operatoire
- la relation entre embeddings, index et qualite de retrieval
- les criteres qui font choisir une solution managee ou plus ouverte

## Piste de depart
Commencez par une matrice de decision simple avant de benchmarker trop tot.
